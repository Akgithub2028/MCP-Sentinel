# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The maintainers of the **MCP Security Red-Team & Defense Toolkit** take security vulnerabilities seriously.

If you discover a security vulnerability in this project:
1. **Do not** report it publicly on GitHub Issues.
2. Email your findings and reproduction steps to **`security@example.com`**.
3. You will receive an acknowledgment within 24 hours.
4. We aim to release a patch or mitigation within 7 days of confirmation.
